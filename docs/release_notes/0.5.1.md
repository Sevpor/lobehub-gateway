# 0.5.1

## Added

- Device health uploads via `device_metrics` and history queries via `POST /api/device/metrics`, including reads while devices are offline.
- LLM Relay endpoints `llm-execute`, `llm-cancel`, and `llm-close`, with execution routed preferentially to the initiating client and replay limited to open, unexpired attempts.

## Compatibility

- Tool calls retain their request ID across device reconnects, with up to three retransmissions. The wait includes the execution timeout and a 45-second recovery window; the default total wait is 75 seconds. Reverse proxies must allow this waiting period. Retransmission does not guarantee exactly-once execution.
- Agent inactivity watchdogs start at initialization and use 30-minute windows for regular runs or 60-minute windows for heterogeneous agents. Backend activity refreshes the timer.
- Device health history is bounded, retained in memory for up to 48 hours, and lost on restart.

## Distribution

- Includes upstream `0.5.0`.
- Docker images are built for linux/amd64 on a self-hosted Linux runner and published to `ghcr.io/zhouguanyang/lobehub-gateway`.
